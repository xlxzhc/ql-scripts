
# ql-scripts

青龙面板自动化任务脚本合集，聚焦于签到、任务、步数、通知与辅助脚本等自动化场景。

## 📁 项目结构

```
ql-scripts/
├── jlc.py                  # 嘉立创签到脚本
├── ahdx.js                 # 安徽电信小程序签到脚本
├── fenxsh.js               # 粉象生活任务脚本
├── xxyx.js                 # 晓晓优选能量任务脚本
├── xinxi.js                # 辛喜日常任务脚本
├── qmsd.js                 # 全棉时代签到+种棉花脚本
├── xiaomi_motion.js        # 小米运动/Zepp Life 刷步脚本
├── sendNotify.js           # 青龙通知模块
├── userscripts/            # 油猴脚本目录
│   └── jlc_token.js        # 嘉立创/开源平台 Token 抓取助手
├── README.md               # 项目说明
```

## 🧩 脚本列表

### 1. 嘉立创自动签到 (jlc.py)

自动完成嘉立创平台的每日签到任务，并支持多账号执行与连续签到奖励领取。

- ✅ 自动签到
- ✅ 自动领取连签奖励
- ✅ 支持多账号
- ✅ 账号信息脱敏显示
- ✅ 青龙通知推送

环境变量：

- `jlcToken`：嘉立创 Token，多账号用 `&`、换行符或 `#` 分隔

获取方式：

1. 安装油猴脚本管理器
2. 导入 `userscripts/jlc_token.js`
3. 打开 `https://m.jlc.com` 登录
4. 点击页面右侧的“抓取Token”按钮
5. 自动复制 Token 至剪贴板

定时任务示例：

```bash
cron: 0 8 * * *
```

自动完成晓晓优选平台的每日任务与签到，获取能量并支持可选自动兑换。

- ✅ 自动签到
- ✅ 完成分享/浏览/视频类任务
- ✅ 支持多账号执行
- ✅ 能量获取统计
- ✅ 可选自动兑换最便宜商品

环境变量：

- `XXYX_TOKENS`：用户 token，多个账号用 `&` 分隔
- `XXYX_EXCHANGE`：设置为 `true` 开启自动兑换

```text
https://plus.web.xxyx.ltd/#/?uid=2042976&source=cityChallengeOther
```

### 3. 辛喜任务脚本 (xinxi.js)

用于自动完成辛喜平台相关日常任务，支持按 token 批量执行，并具备任务列表解析与自动化提交逻辑。

- ✅ 自动签到
- ✅ 完成日常任务
- ✅ 支持多账号 token 批量执行
- ✅ 兼容换行、`&`、`|`、`,`、JSON 格式输入
- ✅ 可识别 `id#token` 以及普通 token 形式

环境变量：

- `XinXi`：辛喜 token，支持以下形式：
  - 单行一个 token
  - 多个 token 用 `&` / `|` / `,` / 换行分隔
  - `id#token` 组合
  - JSON 数组格式，例如：

```bash
[{"id":"10001","token":"xxx"},{"id":"10002","token":"yyy"}]
```

示例：

```bash
XinXi="token1\ntoken2\n12345#token3"
```

### 4. 粉象生活任务脚本 (fenxsh.js)

自动完成粉象生活 App 的签到与日常任务，支持多账号执行。

- ✅ 获取用户信息并检查账号状态
- ✅ 自动签到与完成特殊任务
- ✅ 获取待完成任务并逐项执行
- ✅ 支持多账号
- ✅ 执行结束后通过 `sendNotify.js` 推送运行日志

环境变量：

- `fenxiang`：账号参数，单个账号格式为 `did#finger#token#oaid`，多个账号用 `&` 或换行分隔

示例：

```bash
fenxiang="did1#finger1#token1#oaid1&did2#finger2#token2#oaid2"
```

也可以在脚本顶部的 `localCookie` 中填写账号参数；有效值会优先于环境变量。需要通知推送时，请按通知模块的说明配置推送环境变量。

### 5. 小米运动刷步数 (xiaomi_motion.js)

自动修改小米运动 / Zepp Life 的步数数据，支持多账号与随机步数范围控制。

- ✅ 支持手机号和邮箱登录
- ✅ 支持多账号批量执行
- ✅ 可自定义步数范围
- ✅ Token 智能缓存
- ✅ 详细日志输出
- ✅ 青龙通知推送

环境变量：

方式一：推荐

- `XIAOMI_ACCOUNTS`：`账号&密码&步数范围`，多个账号用 `#` 分隔

示例：

```bash
XIAOMI_ACCOUNTS="13800138000&123456&15000-20000#user@example.com&654321&18000"
```

方式二：分别配置

- `XIAOMI_USERS`：用户名（手机号或邮箱），多个用 `#` 分隔
- `XIAOMI_PASSWORDS`：密码，多个用 `#` 分隔
- `XIAOMI_STEPS`：步数范围，多个用 `#` 分隔，可选

步数范围说明：

- `15000-20000`：随机生成该区间步数
- `18000`：在 `16000-20000` 区间随机生成
- 默认范围：`8000-25000`

定时任务示例：

```bash
cron: 0 9,15 * * *
```

### 6. 安徽电信小程序签到 (ahdx.js)

自动完成「安徽电信」小程序每日签到，通过自建**取码服务**实时获取微信 code，实现无人值守运行。

- ✅ 自动签到并领取星钻
- ✅ 自动查询星钻 / 权益金余额
- ✅ 通过取码服务自动获取 wxcode，无需手动抓包
- ✅ 支持多账号
- ✅ 青龙通知推送

环境变量：

- `AnHuiTelecom`：账号列表，单个账号格式 `备注#凭证`，多账号用换行或 `&` 分隔
  - **取码模式（推荐）**：`备注#ref`，`ref` 为取码服务 `/accounts` 中的账号 `id` / `uin` / `openid`
  - **Cookie 模式**：`备注#完整Cookie`（须含 `qdyl=xxx`，仅约 1 小时有效，一般仅用于临时调试）
- `wx_server_url`：取码服务地址，例如 `http://127.0.0.1:8888`
- `wx_server_appid`：可选，默认 `wx8ebdb28d971c6097`（**安徽电信公众号** appid，一般无需修改）

示例：

```bash
AnHuiTelecom="188****8888#1"
wx_server_url="http://127.0.0.1:8888"
```

多账号示例：

```bash
AnHuiTelecom="188****8888#1
               177****7777#2"
```

⚠️ 使用前须知：

1. `qdylNew/login` 校验的是**安徽电信公众号**的网页授权 code，因此取码时必须使用公众号 appid `wx8ebdb28d971c6097`；若误用小程序 appid，登录会返回 `401 缺少必要参数,请从活动页进入`。
2. 所用微信号**必须先关注「安徽电信」公众号**，否则登录返回 `402 用户未关注安徽电信公众号`。
3. 微信 code 为一次性凭证，**单次运行共申请 2 个**（1 个用于登录、1 个用于查询余额）。

取码服务（YYB Go）：

- 核心接口：`POST /wxapp/getCode`，请求体 `{"ref":"<账号>","app_id":"<appid>"}`
- 需先通过 `POST /qr` 扫码登录微信账号，再用 `GET /accounts` 查询账号 `ref`

定时任务示例：

```bash
cron: 1 10,18 * * *
```

### 7. 全棉时代签到 + 种棉花 (qmsd.js)

自动完成「全棉时代」小程序每日签到与种棉花日常，通过自建**取码服务**实时获取微信 code，实现无人值守运行。

- ✅ 自动签到领取积分
- ✅ 自动种树（尚未种树时按成长目标自动种下一棵）
- ✅ 自动浇水（水滴不足 30 时停止）
- ✅ 自动完成日常任务、庄园小课堂答题与宝箱、阳光领取与消耗
- ✅ 通过取码服务自动获取 wxcode，无需手动粘贴易过期的 `code#token`
- ✅ 支持多账号
- ✅ 青龙通知推送

环境变量：

- `qmzmh`：账号列表，单个账号格式 `openid#备注`（备注可省略），多账号用换行或 `&` 分隔
- `wx_server_url`：取码服务地址，默认 `http://192.168.31.196:8787`
- `wx_auth`：取码服务的 auth 令牌（smallcat 需要；取码服务无鉴权时留空即可）
- `qmzmh_prize_id`：可选，种树成长目标奖品 id，默认 `1046`（加厚棉柔巾 6片/包\*1包）
  - 可选值来自 `GET https://sg01.purcotton.com/api/prize/home`；若指定的 id 已下架，脚本会自动回退为列表首项

示例：

```bash
qmzmh="openid1#账号A
openid2#账号B"
wx_server_url="http://127.0.0.1:8000"
```

取码服务要求：

- 需支持 `POST /wx/code`，请求体 `{"appid":"wxdfcaa44b1aa891a7","openid":"<openid>"}`
- 本机「应用宝 Go 控制台」（`127.0.0.1:8000`）已验证兼容该接口，且**无需 auth 令牌**
- openid 可通过取码服务的 `GET /accounts` 查询

运行说明：

1. 会员**未绑定手机号**时无法签到，脚本会提示跳过（需先在小程序内完成手机号授权注册）。
2. 日常任务按固定顺序执行：逛甄选好棉品 → 浏览新用户专区 → 棉花工厂 → 三餐福袋 → 社区送福利 → 订阅奖励提醒 → 庄园小课堂 → 签到。
3. `三餐福袋` 有开放时段限制，`社区送福利` 可能返回「找不到任务，或任务已经结束」，均属正常。
4. 仅给**自己的树**浇水，不含「给好友浇水」的社交玩法。

定时任务示例：

```bash
cron: 30 8 * * *
```

## 🚀 安装依赖

在青龙环境中，通常需要安装以下依赖：

```bash
npm install axios tough-cookie undici crypto-js
```

如果青龙依赖管理中没有自动安装，可手动添加：

- `axios`
- `tough-cookie`
- `undici`（通知模块使用）
- `crypto-js`
- `crypto`（Node.js 内置，通常无需额外安装）
- 小米运动脚本使用 Node.js 内置 `crypto.randomUUID()`，无需安装 `uuid`
- 全棉时代脚本（`qmsd.js`）与安徽电信脚本（`ahdx.js`）仅需 `axios` 与 Node 内置的 `crypto` / `fs` / `path`

## 📝 使用方法

### 1. 添加脚本

将脚本上传到青龙面板的 `/ql/scripts` 目录，或通过订阅功能添加。

### 2. 配置环境变量

在青龙面板“环境变量”中设置对应脚本所需的变量。

### 3. 添加定时任务

在青龙面板“定时任务”中新增任务，选择对应脚本文件并设置 cron 表达式。

### 4. 手动测试

首次配置后建议先手动执行一次脚本，确认各项功能正常。

## ⚠️ 注意事项

1. 账号信息请勿明文硬编码，优先使用青龙环境变量。
2. 小米运动脚本会在本地生成缓存文件，减少重复登录次数。
3. 全棉时代脚本会在脚本目录生成 `quanmianshidai_token_cache.json`，仅用于缓存账号的设备 GUID，可安全删除。
4. 任务和步数配置应尽量符合平台正常范围，避免被判定异常。
5. 多账号执行时请适当留出间隔，降低请求频率。
6. 如需通知推送，请确保青龙的通知模块已正确配置。

## 🔧 常见问题

### 嘉立创脚本

- Token 失效：检查 `jlcToken` 是否正确，是否含多余空格或分隔错误。
- 签到失败：确认网络状态并查看脚本日志中的具体错误信息。

### 晓晓优选脚本

- Token 无效：检查 `XXYX_TOKENS` 是否配置正确。
- 任务失败：查看日志中的接口返回，可能因平台接口更新导致。
- 兑换失败：确认能量足够且商品库存正常。

### 小米运动脚本

- 登录失败：检查账号密码和账号类型是否正确。
- 修改步数失败：通常为 Token 失效或网络异常。
- 缓存问题：删除 `cache/` 下对应缓存文件后重试。

### 粉象生活脚本

- 未找到账号：确认 `fenxiang` 格式为 `did#finger#token#oaid`，多账号使用 `&` 或换行分隔。
- 通知未收到：确认 `sendNotify.js` 可用，并已配置至少一种推送渠道。

### 辛喜脚本

- 无法读取账号：确认环境变量 `XinXi` 格式无误。
- 任务异常：检查 token 是否有效，以及接口返回状态。

### 安徽电信脚本

- 登录返回 `401 缺少必要参数,请从活动页进入`：取码所用 appid 不对，必须使用**公众号** appid `wx8ebdb28d971c6097`，不能用小程序的 `wx1c9e55df51ce792b`。
- 登录返回 `402 用户未关注安徽电信公众号`：用该微信号关注「安徽电信」公众号后重试。
- 登录返回 `400 请勿重复点击`：登录过于频繁，等待片刻再执行。
- 签到返回 `今日已签到`：属正常状态，说明当日任务已完成。
- 签到返回 `页面已过期，请重新进入页面哦`：Cookie 模式下的登录态已过期（约 1 小时），请改用取码模式。
- 取码失败或无法连接：确认 `wx_server_url` 可访问，且取码服务中该账号 `status` 为 `alive`。
- 排查思路：先确认取码服务能正常返回 code（`POST /wxapp/getCode`）；若微信侧取码成功而登录仍失败，则多半是 appid 用错或该微信号未关注公众号，可对照上面两条提示逐项排查。

### 全棉时代脚本

- 取码失败（`wx_server 获取 code 失败`）：确认 `wx_server_url` 可访问（`GET /health`），且该 openid 已在取码服务中登录（`GET /accounts` 中 `status` 为 `alive`）。smallcat 偶发会话抖动，脚本会自动重试 4 次。
- 提示「该账号尚未绑定手机号」：该微信号未注册为会员，需先在小程序「全棉时代」内完成手机号授权。
- 签到返回 `1` / `0`：分别表示「签到成功」/「今日已签到」，均为正常状态。
- 未种树时脚本会先按 `qmzmh_prize_id` 自动种树再浇水；若种树不成功，多为指定奖品已下架，可改用 `GET /api/prize/home` 中的有效 id。
- 取码服务不需要认证时，`wx_auth` 留空即可，脚本不会因缺少该变量而退出。
- 通知未收到：确认 `sendNotify.js` 可用，并已配置至少一种推送渠道。
