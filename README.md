
# ql-scripts

青龙面板自动化任务脚本合集，聚焦于签到、任务、步数、通知与辅助脚本等自动化场景。

## 📁 项目结构

```
ql-scripts/
├── jlc.py                  # 嘉立创签到脚本
├── xxyx.js                 # 晓晓优选能量任务脚本
├── xinxi.js                # 辛喜日常任务脚本
├── xiaomi_motion.js        # 小米运动/Zepp Life 刷步脚本
├── sendNotify.js           # 青龙通知模块
├── userscripts/            # 油猴脚本目录
│   └── jlc_token.js        # 嘉立创/开源平台 Token 抓取助手
├── README.md               # 项目说明
```

## 🧩 脚本列表

### 1. 嘉立创自动签到 (jlc.py)

自动完成嘉立创平台的每日签到任务，并支持多账号执行与连续签到奖励领取。

- ✅ 自动签到
- ✅ 自动领取连签奖励
- ✅ 支持多账号
- ✅ 账号信息脱敏显示
- ✅ 青龙通知推送

环境变量：

- `jlcToken`：嘉立创 Token，多账号用 `&`、换行符或 `#` 分隔

获取方式：

1. 安装油猴脚本管理器
2. 导入 `userscripts/jlc_token.js`
3. 打开 `https://m.jlc.com` 登录
4. 点击页面右侧的“抓取Token”按钮
5. 自动复制 Token 至剪贴板

定时任务示例：

```bash
cron: 0 8 * * *
```

### 2. 晓晓优选能量任务 (xxyx.js)

自动完成晓晓优选平台的每日任务与签到，获取能量并支持可选自动兑换。

- ✅ 自动签到
- ✅ 完成分享/浏览/视频类任务
- ✅ 支持多账号执行
- ✅ 能量获取统计
- ✅ 可选自动兑换最便宜商品

环境变量：

- `XXYX_TOKENS`：用户 token，多个账号用 `&` 分隔
- `XXYX_EXCHANGE`：设置为 `true` 开启自动兑换

入口地址：

```text
https://plus.web.xxyx.ltd/#/?uid=2042976&source=cityChallengeOther
```

### 3. 辛喜任务脚本 (xinxi.js)

用于自动完成辛喜平台相关日常任务，支持按 token 批量执行，并具备任务列表解析与自动化提交逻辑。

- ✅ 自动签到
- ✅ 完成日常任务
- ✅ 支持多账号 token 批量执行
- ✅ 兼容换行、`&`、`|`、`,`、JSON 格式输入
- ✅ 可识别 `id#token` 以及普通 token 形式

环境变量：

- `XinXi`：辛喜 token，支持以下形式：
  - 单行一个 token
  - 多个 token 用 `&` / `|` / `,` / 换行分隔
  - `id#token` 组合
  - JSON 数组格式，例如：

```bash
[{"id":"10001","token":"xxx"},{"id":"10002","token":"yyy"}]
```

示例：

```bash
XinXi="token1\ntoken2\n12345#token3"
```

### 4. 小米运动刷步数 (xiaomi_motion.js)

自动修改小米运动 / Zepp Life 的步数数据，支持多账号与随机步数范围控制。

- ✅ 支持手机号和邮箱登录
- ✅ 支持多账号批量执行
- ✅ 可自定义步数范围
- ✅ Token 智能缓存
- ✅ 详细日志输出
- ✅ 青龙通知推送

环境变量：

方式一：推荐

- `XIAOMI_ACCOUNTS`：`账号&密码&步数范围`，多个账号用 `#` 分隔

示例：

```bash
XIAOMI_ACCOUNTS="13800138000&123456&15000-20000#user@example.com&654321&18000"
```

方式二：分别配置

- `XIAOMI_USERS`：用户名（手机号或邮箱），多个用 `#` 分隔
- `XIAOMI_PASSWORDS`：密码，多个用 `#` 分隔
- `XIAOMI_STEPS`：步数范围，多个用 `#` 分隔，可选

步数范围说明：

- `15000-20000`：随机生成该区间步数
- `18000`：在 `16000-20000` 区间随机生成
- 默认范围：`8000-25000`

定时任务示例：

```bash
cron: 0 9,15 * * *
```

### 6. 油猴脚本 (userscripts/jlc_token.js)

用于移动端抓取嘉立创 Token 或开源硬件平台 Cookie，并自动复制到剪贴板。

- ✅ 一键提取 JLC Token
- ✅ 一键提取开源硬件平台 Cookie
- ✅ 自动复制到剪贴板
- ✅ 适配移动端悬浮触发方式

支持平台：

- 嘉立创：`m.jlc.com`
- 开源硬件平台：`oshwhub.com`

## 🚀 安装依赖

在青龙环境中，通常需要安装以下依赖：

```bash
npm install axios crypto uuid
```

如果青龙依赖管理中没有自动安装，可手动添加：

- `axios`
- `crypto`（Node.js 内置，通常无需额外安装）
- `uuid`（实际代码中可使用内置 `crypto.randomUUID()`，也可按需安装）

## 📝 使用方法

### 1. 添加脚本

将脚本上传到青龙面板的 `/ql/scripts` 目录，或通过订阅功能添加。

### 2. 配置环境变量

在青龙面板“环境变量”中设置对应脚本所需的变量。

### 3. 添加定时任务

在青龙面板“定时任务”中新增任务，选择对应脚本文件并设置 cron 表达式。

### 4. 手动测试

首次配置后建议先手动执行一次脚本，确认各项功能正常。

## ⚠️ 注意事项

1. 账号信息请勿明文硬编码，优先使用青龙环境变量。
2. 小米运动脚本会在本地生成缓存文件，减少重复登录次数。
3. 任务和步数配置应尽量符合平台正常范围，避免被判定异常。
4. 多账号执行时请适当留出间隔，降低请求频率。
5. 如需通知推送，请确保青龙的通知模块已正确配置。

## 🔧 常见问题

### 嘉立创脚本

- Token 失效：检查 `jlcToken` 是否正确，是否含多余空格或分隔错误。
- 签到失败：确认网络状态并查看脚本日志中的具体错误信息。

### 晓晓优选脚本

- Token 无效：检查 `XXYX_TOKENS` 是否配置正确。
- 任务失败：查看日志中的接口返回，可能因平台接口更新导致。
- 兑换失败：确认能量足够且商品库存正常。

### 小米运动脚本

- 登录失败：检查账号密码和账号类型是否正确。
- 修改步数失败：通常为 Token 失效或网络异常。
- 缓存问题：删除 `cache/` 下对应缓存文件后重试。

### 辛喜脚本

- 无法读取账号：确认环境变量 `XinXi` 格式无误。
- 任务异常：检查 token 是否有效，以及接口返回状态。
